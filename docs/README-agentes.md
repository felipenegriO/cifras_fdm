# Uso dos agentes

Este projeto tem dois agentes de apoio:
- Dev: docs/agent-dev.md
- Tester: docs/agent-tester.md

Como usar
- Forneca ao agente o arquivo correspondente como contexto.
- Descreva a tarefa de forma objetiva (o que mudar, onde, criterios).
- Para testes, informe paginas e fluxos prioritarios.
